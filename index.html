Social Media Analytical Platform

Data Scientist · Web Application · 2024

01 — Context

Social media contains large volumes of unstructured text. AI-assisted analytics must interpret not only what users discuss, but also the quality and logic behind those conversations. Logical fallacies can distort context and lead analysis toward misleading conclusions.

02 — Problem

Process large volumes of social text and identify logical fallacies so the system could produce more contextually reliable analysis.

03 — My responsibility

I designed the data and prompt-engineering workflow from preparation through evaluation.

  • Collected and prepared social media text
  • Cleaned and transformed unstructured data
  • Developed NLP, topic, and sentiment workflows
  • Designed fallacy-aware prompt evaluation
  • Structured outputs into SQL datasets

04 — Data

10,000+ social media records covering conversations, engagement, topic and sentiment information, fallacy evaluations, and chatbot-generated analytical responses.

05 — Analytical pipeline
10,000+ records→Text cleaning→NLP analysis→Topic modeling→Sentiment→Fallacy detection→AI evaluation→Structured output

06 — Solution

A fallacy-aware social media analytics web application that analyzed what people discussed, how they felt, and the reasoning behind those conversations.

PythonPandasNLTKScikit-learnNLPLDASQLPrompt Engineering
Core idea

Go beyond conventional topic and sentiment analysis by evaluating the quality of reasoning.

07 — Impact

96% ↓Logical fallacy in AI-assisted analysisImproved contextual reliability

08 — What I learned

Reliable AI analytics requires more than extracting patterns—the quality of reasoning behind an output must also be evaluated. Working with 10,000+ records strengthened my ability to connect data preparation, contextual analysis, AI evaluation, and measurable improvement.

Diabetic Retinopathy Detection

Machine Learning Engineer & Project Manager · Mobile Application · 2023

01 — Context

Diabetic retinopathy can cause preventable vision loss when not detected early. Limited screening access creates an opportunity for image-based AI to support preventive healthcare.

02 — Problem

Develop an image-classification model for retinal fundus images and integrate it into an accessible mobile solution aligned with user and healthcare needs.

03 — My responsibility

I worked as both Machine Learning Engineer and Project Manager.

  • Curated and preprocessed the dataset
  • Developed, trained, and evaluated the model
  • Supported deployment and app integration
  • Coordinated a 10-member multidisciplinary team
  • Aligned technical delivery with user needs

04 — Data

15,000 retinal fundus images covering diabetic-retinopathy labels, dataset curation, preprocessing, normalization, augmentation, training, and evaluation.

05 — End-to-end ML pipeline
Requirements→15K images→Preprocessing→Augmentation→CNN development→Training→Evaluation→Mobile integration

06 — Solution

An AI-powered mobile application that analyzed retinal fundus images with a trained CNN model to support early diabetic-retinopathy screening.

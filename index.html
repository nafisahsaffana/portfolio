Context

Social media contains large volumes of unstructured text. AI-assisted analytics must interpret not only what users discuss, but also the quality and logic behind those conversations. Logical fallacies can distort context and lead analysis toward misleading conclusions.

How it solved

I built an analytical workflow that transformed 10,000+ unstructured social media records into structured data using Python and NLP to extract conversational context, designed and iterated fallacy-aware prompts to help a chatbot identify flawed reasoning, evaluated the outputs for reliability, and organized the processed conversations, fallacy classifications, and evaluation results into SQL-based datasets for consistent analysis and comparison.

The resulting workflow reduced logical fallacies in AI-assisted analysis by 96%, demonstrating how prompt engineering, structured data, and systematic evaluation can improve the reliability of AI-generated insights.
